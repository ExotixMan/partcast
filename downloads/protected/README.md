# Protected sales review workbook

[Download Sales_Reconciliation_Review_Protected.xlsx](Sales_Reconciliation_Review_Protected.xlsx). On GitHub, use the download button if a preview opens.

Open the downloaded workbook in Microsoft Excel and enter the password provided separately in the PartCast conversation. The password is not stored in this repository. The workbook uses password-based Office encryption, rather than worksheet edit protection.

The encrypted workbook contains the existing confirmed correction, source lines and owner-answer worksheet. Its decrypted contents are byte-identical to the private review workbook. No new sales were added by this delivery change.

Keep your password and any decrypted copy private. This is a review workbook, not a forecasting import. Follow its READ_FIRST sheet and complete Owner_Answers from receipts or the owner's sales log.
