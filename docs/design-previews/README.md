Sales and deliveries share Sell or receive. Inventory contains part details and stock corrections, with read-only controls for Cashiers. Part photos fit their frames without cropping and open a gallery independently of adding an item to a basket. Login requires a password followed by the emailed code.

The sign-in previews show the plain, solid-color layout: one form, a simple PartCast wordmark, labeled Show/Hide password controls, and an explicit password/email-code sequence. They use blank fields or a fictional staff account. No real credentials or store records are shown.

To save all application files and these pictures, open the repository branch on GitHub and choose Code → Download ZIP. Screenshots do not establish a live deployment.
